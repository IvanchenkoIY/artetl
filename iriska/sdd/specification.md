# Главная страница «Уральская тропа» и базовый стиль

Реализация главной страницы и базового стиля для демонстрационного сайта спортивного туризма. Изменяются только web/index.html и web/style.css. Внешние ресурсы запрещены. Визуальная приёмка не входит в автоматическую проверку.

## Требования

- **REQ-001**: Главная страница содержит заголовок «Уральская тропа» и упоминание «Конжаковский».
  Проверка: test command-1
- **REQ-002**: Навигация содержит ссылки на /routes, /signup и подключает /style.css.
  Проверка: test command-1
- **REQ-003**: Страница содержит изображение /assets/konzhak.jpg с атрибутом alt.
  Проверка: test command-1
- **REQ-004**: HTML-документ имеет lang="ru" и семантические теги <nav> и <main>.
  Проверка: test command-1
- **REQ-005**: Стили включают адаптивность (@media), видимый фокус (:focus) и объем более 300 символов.
  Проверка: test command-1
- **REQ-006**: Код страницы не содержит внешних ссылок (http:// или https://).
  Проверка: test command-1

## Вне scope

- Реализация страниц /routes, /trail, /signup, /about
- Изменение логики сервера или валидации
- Добавление внешних шрифтов, библиотек или CDN
