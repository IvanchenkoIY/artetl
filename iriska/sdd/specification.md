# Реализация страницы /about и доработка CSS

Задача: реализовать страницу /about и доработать CSS. Ограничения: только web/about.html и web/style.css. В about.html должны присутствовать слова «демонстрационный», «данные», «лицензия», «Антонов Д. В.», «public domain», ссылка на /assets/konzhak.jpg, nav, main, lang="ru". CSS должен сохранять @media и :focus-visible. Внешние ссылки запрещены. Тест command-1 проверяет наличие этих слов в HTML /about.

## Требования

- **REQ-001**: Страница /about содержит слово «демонстрационный» (в любом регистре).
  Проверка: test command-1

  Проверка: test command-1
- **REQ-003**: Страница /about содержит слово «лицензия» (в любом регистре).
  Проверка: test command-1
- **REQ-004**: Страница /about содержит имя автора «Антонов Д. В.» (в любом регистре).
  Проверка: test command-1
- **REQ-005**: Страница /about содержит ссылку на изображение /assets/konzhak.jpg.
  Проверка: test command-1
- **REQ-006**: Страница /about содержит атрибут lang="ru" в теге <html>.
  Проверка: test command-1
- **REQ-007**: Страница /about содержит семантический элемент <nav>.
  Проверка: test command-1
- **REQ-008**: Страница /about содержит семантический элемент <main>.
  Проверка: test command-1
