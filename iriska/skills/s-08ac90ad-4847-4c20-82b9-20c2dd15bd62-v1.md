# Небольшой HTTP-сервис
Применяется к developer и tester. Не меняет права процесса.
Используй стандартную библиотеку выбранного языка. Проверяй разрешённые пути и методы; не открывай произвольные файлы. Ограничивай тело запроса, валидируй поля и отклоняй неизвестные значения. Не возвращай секреты и traceback. Экранируй пользовательский текст в HTML; для ответа формы предпочитай JSON. Демонстрационные заявки сохраняй только в выделенный каталог данных и никогда не коммить персональные данные. Добавляй понятный статус и корректный Content-Type; тестируй happy path и отрицательные случаи. Не отключай и не ослабляй исходные тесты.

For this task, preserve semantic HTML landmarks and existing HTTP tests.
