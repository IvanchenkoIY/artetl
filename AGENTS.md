# Проверенные сведения для «Уральской тропы»

Конжаковский Камень — вершина Северного Урала, высота 1569 м. Не называй его высочайшей точкой Северного Урала. Таганай — национальный парк на Южном Урале. Иремель находится на Южном Урале. Не придумывай начальную точку, населённый пункт, длину маршрута, озёра на вершине, стоимость, расписание или гарантии безопасности: этих сведений в задаче нет. Не выдавай фиксированное количество воды и иной инвентарь за универсальную рекомендацию; подготовку обсуждают с организатором для конкретных условий.

Для региона используй явную подпись «Северный Урал» либо «Южный Урал». Различай буквальное требование интерфейса и похожее по смыслу выражение: «на Северном Урале» не заменяет требуемую подпись «Северный Урал». После изменения проверь полный возвращаемый HTML; утверждение summary не доказывает наличия строки в файле. Тесты и их исходники не изменяются.
