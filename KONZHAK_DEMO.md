# Демонстрационный сайт «Конжак»

Пять страниц: /, /cabins, /quad, /views, /booking.
Python stdlib; запуск python app.py, PORT по умолчанию 8080, SQLITE_PATH задаёт
путь к сохраняемой базе (в контейнере /data/registrations.sqlite3).
Заявки трёх услуг сохраняются в bookings; прежняя форма /register —
в registrations. Нет оплаты, рассылки и реального резервирования услуг.

Фотографии локальные, суммарно менее 180 КБ, источники и лицензии в PHOTO_CREDITS.md
и в подписях страниц. Код страниц — src/page.py, src/site.py, src/activities.py;
форма и сохранение — src/booking.py; HTTP — src/server.py.

Проверки: python -m unittest discover -s tests -v, внутри контейнера с отключённой
сетью и непривилегированным пользователем. Независимый test_site_contract.py
защищён от правок агентами. Репозиторий не содержит пользовательской базы.

Новая задача Ириски должна начинаться от опубликованной ветки предыдущей
успешной задачи. Каждая задача создаёт собственную task/UUID; main не меняется.
Содержимое — учебная демонстрация, не проверенный маршрут или предложение услуг.
