# Требования сайта

REQ-001: главная страница, локальный стиль и фото. REQ-002: маршруты Конжак/Таганай/Иремель и описание Конжака. REQ-003: демонстрационная заявка с серверной валидацией и сохранением. REQ-004: информация о проекте, авторе фото и персональных данных. REQ-005: отрицательные проверки ввода и защита путей.
Каждая итерация использует command-1 текущей версии runtime, кумулятивно проверяющий прежние функции. Детальная утверждённая спецификация задачи — iriska/sdd/specification.{md,json}. Визуальная приёмка отдельно, не заменяется HTTP-тестами.
Вне scope: платежи, настоящий туроператор, гарантии безопасности маршрутов, онлайн-карты, сторонние API и реальные ПДн.
