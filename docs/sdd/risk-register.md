# Риски и ограничения

| Риск | Контроль | Остаточное ограничение |
|---|---|---|
| Выдуманные сведения модели | Проверенные факты skill, независимые проверки регионов/высоты, ручное чтение | Строковые тесты не подтверждают любую географическую фразу |
| ПДн в учебной заявке | Только вымышленные данные, пояснение на форме, /data вне Git | Нет production-политики хранения и согласия |
| Утечка учётных данных через предпросмотр | Отдельный origin *.localhost, доверенный proxy убирает Cookie/Authorization, backend без опубликованных портов | Это локальный стенд, не банковский sandbox |
| Ошибка слабой модели | Малые задачи, ≤2файла/unit, полные текущие файлы, реальные тесты, ограниченные retry/repair | Работа не гарантирована без участия человека |
| Незащищённый публичный сервис | Публикация только localhost, нет оплат и настоящих броней | Для production нужны TLS/лимиты/аутентификация/антиспам/аудит |
