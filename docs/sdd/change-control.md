# Управление изменениями

Владелец user утверждает цель и ограничения; администратор разрешает Git/runtime/политику, человек проверяет SPEC и PLAN. В этой порученной демонстрации согласования автоматизированы через обычные API, а не нажаты спящим владельцем.
Каждая задача получает собственную ветку task/UUID и frozen материалы. Следующая начинается от завершённой ветки предыдущей. Все записи модели проходят серверный policy, commit и push. Пауза не удаляет данные.
Для внешней правки: пауза → fetch/checkout ветки → собственный commit/push → получить изменения в Ириске → просмотр hash инструкций/спецификации → новый baseline/SPEC/PLAN. Изменения проектного материала публикуются новой версией; задача изменяет свои выбранные MD-файлы отдельно.
