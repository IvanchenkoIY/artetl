# Проверка и трассируемость

Фазы1–5: REQ-001..005 → малый план задачи → command-1 соответствующей фазы → FINAL_TEST на точном SHA. Квитанции фактически завершённых задач перечислены в iterations/*.md.
В итоговой задаче REQ-101 → command-1 (регрессии), REQ-102 → command-2 (главная), REQ-103 → command-3 (маршруты), REQ-104 → command-4 (Конжак). REQ-105/106 требуют браузерной проверки1440/390px и подтверждения формы на точном финальном SHA. До завершения эти два критерия не объявлены принятыми.
Все попытки, полные JSON вызовов модели, stdout/exitCode тестов и действия человека доступны в истории Ириски. Сводка модели не заменяет receipt. Тесты независимы от разработчика-модели. Изменение ошибки самого теста явно фиксируется человеческим коммитом и требует повторного прогона.
