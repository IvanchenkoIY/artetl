# Принципы «Уральской тропы»

Владелец user (лидер демонстрационного проекта). Пять учебных итераций, без реальных персональных данных, оплат и бронирования. Стандартная библиотека java, локальные ресурсы и лицензированное фото. Внешняя сеть в работе сайта не нужна.
Существующие тесты неизменяемы; модель меняет два файла за задачу. SPEC и PLAN согласовываются отдельно, Git — ветка task/UUID, тесты — отдельный контейнер без сети. Успех только по фактическому receipt на точном коммите.
