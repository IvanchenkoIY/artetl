# Технический дизайн

Стандартный HTTP-сервер обслуживает белый список пяти страниц и двух статических ресурсов. POST /signup валидирует поля через register, сервер сохраняет заявку вне дерева исходников. Никакой базы, библиотеки и сети не требуется.
## ADR-001
Статус: принято владельцем демонстрации. Стандартная библиотека выбрана для воспроизводимых офлайн-проверок Java/Python. Минус: это учебный сайт без production TLS/аутентификации/антиспама.
## Риски
Не использовать реальные ПДн. Предпросмотр слушает только localhost хоста; данные — отдельный временный каталог.
## Контракты
Пути /, /routes, /trail, /signup, /about; POST /signup: 201 валидные поля, 400 неверные, неизвестный путь 404, тело >4096 байт 413.
