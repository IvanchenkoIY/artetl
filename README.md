# Уральская тропа · java

Учебный сайт спортивного туризма. Заявки демонстрационные, без оплаты и реального бронирования. Не используйте реальные персональные данные.
Стандартная библиотека, пять страниц, локальное изображение; внешние зависимости и сеть не нужны.

Запуск: `javac -d /tmp/ural-classes src/*.java && java -cp /tmp/ural-classes Server 8080`. Проверка: `java tests/Check.java 5`.
SDD: docs/sdd; инструкции и навыки: AGENTS.md и iriska/.
